# Dark Mode Implementation Plan for KogniTerm Desktop

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a full 3-way (Light / Dark / System) Dark Mode theme system for KogniTerm Desktop with anti-FOUC initialization, header quick-toggle, and settings modal controls.

**Architecture:** Use a custom React hook `useTheme` synchronized with `localStorage` and `window.matchMedia`. Apply `.dark` CSS class and `color-scheme: dark` to `document.documentElement`. Adapt `index.css` rules for Markdown, user bubbles, sidebars, code cards, and tool badges.

**Tech Stack:** React, TypeScript, Tailwind CSS v4, Lucide React icons, Vite, Tauri.

## Global Constraints

- Preserve default behavior (Light Mode) when no theme preference is saved.
- Ensure anti-FOUC inline script in `index.html` prevents any white flash during app load.
- Ensure all text and UI elements remain high contrast and accessible in both Light and Dark themes.

### Task 1: Create `useTheme` Hook & Anti-FOUC Script

**Files:**

**Interfaces:**

- [ ] **Step 1: Write `useTheme` hook**

Create file `kogniterm-desktop/apps/desktop/src/hooks/useTheme.ts`:

```typescript
import { useState, useEffect } from 'react';

export type ThemeMode = 'light' | 'dark' | 'system';

const STORAGE_KEY = 'kogniterm_theme';

export function useTheme() {
  const [theme, setThemeState] = useState<ThemeMode>(() => {
    const saved = localStorage.getItem(STORAGE_KEY) as ThemeMode | null;
    return saved && ['light', 'dark', 'system'].includes(saved) ? saved : 'system';
  });

  const [systemIsDark, setSystemIsDark] = useState<boolean>(() => {
    return window.matchMedia('(prefers-color-scheme: dark)').matches;
  });

  useEffect(() => {
    const mediaQuery = window.matchMedia('(prefers-color-scheme: dark)');
    const handleChange = (e: MediaQueryListEvent) => {
      setSystemIsDark(e.matches);
    };

    mediaQuery.addEventListener('change', handleChange);
    return () => mediaQuery.removeEventListener('change', handleChange);
  }, []);

  const effectiveTheme: 'light' | 'dark' =
    theme === 'system' ? (systemIsDark ? 'dark' : 'light') : theme;

  useEffect(() => {
    const root = document.documentElement;
    if (effectiveTheme === 'dark') {
      root.classList.add('dark');
      root.style.colorScheme = 'dark';
    } else {
      root.classList.remove('dark');
      root.style.colorScheme = 'light';
    }
  }, [effectiveTheme]);

  const setTheme = (newTheme: ThemeMode) => {
    setThemeState(newTheme);
    localStorage.setItem(STORAGE_KEY, newTheme);
  };

  return { theme, effectiveTheme, setTheme };
}
```

- [ ] **Step 2: Add anti-FOUC inline script to `index.html`**

Modify `kogniterm-desktop/apps/desktop/index.html`:

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <link rel="icon" type="image/svg+xml" href="/vite.svg" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>KogniTerm Desktop</title>
    <script>
      (function() {
        try {
          var savedTheme = localStorage.getItem('kogniterm_theme') || 'system';
          var isDark = savedTheme === 'dark' || 
            (savedTheme === 'system' && window.matchMedia('(prefers-color-scheme: dark)').matches);
          if (isDark) {
            document.documentElement.classList.add('dark');
            document.documentElement.style.colorScheme = 'dark';
          } else {
            document.documentElement.classList.remove('dark');
            document.documentElement.style.colorScheme = 'light';
          }
        } catch (e) {}
      })();
    </script>
  </head>
  <body class="bg-white dark:bg-[#09090b] text-zinc-900 dark:text-zinc-100">
    <div id="root"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```

**Interfaces:**

- [ ] **Step 1: Update `App.tsx` with header theme toggle**

Import `Sun`, `Moon`, `Monitor` from `lucide-react` and `useTheme` from `./hooks/useTheme`.
In `App.tsx`:

```tsx
import { useTheme } from './hooks/useTheme';
import { Sun, Moon, Monitor } from 'lucide-react';
```

Inside component `App()`:

```tsx
const { theme, setTheme } = useTheme();

const toggleThemeQuick = () => {
  if (theme === 'light') setTheme('dark');
  else if (theme === 'dark') setTheme('system');
  else setTheme('light');
};
```

Render theme toggle button in header control actions (near project & auto-approve indicators):

```tsx
<button
  onClick={toggleThemeQuick}
  title={`Tema actual: ${theme === 'light' ? 'Claro' : theme === 'dark' ? 'Oscuro' : 'Sistema'}`}
  className="p-1.5 rounded-lg text-zinc-600 dark:text-zinc-400 hover:bg-zinc-100 dark:hover:bg-zinc-800 transition-colors flex items-center gap-1 cursor-pointer"
>
  {theme === 'light' && <Sun className="w-4 h-4 text-amber-500" />}
  {theme === 'dark' && <Moon className="w-4 h-4 text-indigo-400" />}
  {theme === 'system' && <Monitor className="w-4 h-4 text-zinc-500 dark:text-zinc-400" />}
</button>
```

Ensure top-level containers in `App.tsx` use Tailwind `dark:` variants (`bg-white dark:bg-[#09090b] text-zinc-900 dark:text-zinc-100 border-zinc-200 dark:border-zinc-800`).
